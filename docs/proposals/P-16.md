## Changes
1. **Light visual review (biggest gain).** fit.py already measures the pages and the layout. The visual check keeps
   one image (page 1 of the CV, low detail) and only when fit.py reports something to look at (near the page limit,
   a heading at the bottom of a page); otherwise `visual-review.json` records "fit.py measurements, no image".
   Expected: ~400k fewer characters in the Writer's context per preparation.
2. **PM conversation kept short.** `compression.idle_compact_after_seconds: 3600` in the career-buddy profile (a
   thread you come back to after an hour is compacted before the first reply), and the PM ends each delivered
   package with a pointer to its files (the facts live in files and Baserow, never only in the chat). The user may
   also type `/new` at any time. If Hermes offers a daily automatic session reset for Telegram, use it (to verify
   during the build).
3. **Compact engine output.** `bin/hcb engine run --brief` returns only failing steps, each in one line with the
   fix hint, plus `all_passed`; the full JSON stays in `engine-validation.json`. The Writer uses `--brief`.
4. **Writer pack by section.** `bin/hcb writer-pack --plan <document-plan.json>` writes only the method sections the
   plan needs (no selection-criteria section without a statement, no letter section without a letter) and the
   facts digest without `context_only` cards that `selection.json` left OUT. Large reads (>20k chars) are replaced
   by `search_files` / ranged reads.
5. **One voice pass.** Soul Voice and Humanizer applied together with one combined checklist
   (`references/voice-layers.md`), Soul Voice still winning; one `voice_review` block. Same rules, one round trip
   instead of two or three.
6. **Timing per phase.** `state.event("phase", task_id, role, phase, started_at, ended_at)` for intake, Writer
   draft, engine runs, voice, Recruiter rounds; `bin/hcb dashboard` shows minutes per phase for the last
   preparations, and the Saturday report the median.
7. **Lower reasoning for mechanical steps (optional).** `delegation.reasoning_effort: low` only for delegated
   revise / claim-map tasks if Hermes supports per-task effort; the main Writer draft and the Recruiter keep
   `medium`. Measured with 6 before switching.

## Not changed
