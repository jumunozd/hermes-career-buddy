## Automatic update protocol for Writer
After an explicit selection/edit, append a record here with: stable ID, date actually available, document/context, recipient relationship, exact variants or their durable references, selected wording, explicit user comment, interpretation, scope, and superseded record if relevant. Label evidence as original, AI-adapted, approved AI rewrite, or preference commentary. Record edits as edits, not approval of unedited alternatives. Never infer that all facts in selected text were verified.

Latest explicit instruction takes precedence for its scope. Keep earlier evidence and mark supersession rather than silently overwriting history. Promote a contextual preference to a general rule only on an explicit statement or repeated consistent choices; mark inference until confirmed. A rejected alternative is not a prohibited phrase list.

Persist through authorised file operations in the maintained copy, not the fact bank or global Hermes configuration. If unavailable/read-only, return an unsaved record to the caller; do not claim learning was saved. Infrastructure should serialise concurrent updates and preserve reviewable revisions. Loading the updated record next time is required; a Markdown instruction alone is not an automatic memory service.
